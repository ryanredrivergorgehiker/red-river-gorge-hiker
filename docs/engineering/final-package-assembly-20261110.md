## Controlled assembly and independent verification

The candidate now contains a separate `package` mode in the existing restricted workflow. It preserves the accepted raster source branch and reconstructs each source-free funded allocation from a small SHA-bound controller cursor. Metadata inventory runs in at most 96-wave slices; a fresh verification job repeats the accepted-receipt inventory before saving each checkpoint. The complete inventory is partitioned into the existing bounded native TAR format with generation-pinned per-part descriptors. The entire remaining part/index allocation must fit the unchanged campaign and storage ceilings before parts begin.

Each part is rebuilt from original accepted ranges, checked locally, uploaded create-only with native delivery identity metadata, then downloaded by a fresh verification job. Full archive/member SHA-256, 256px image decoding, regional alpha, native opacity and the complete shared asset references are checked before progression. Three native indexes and inactive catalog candidates are the final assembly outputs. Catalog activation, authenticated delivery and physical iPhone acceptance remain outstanding until separately verified; no flag calls this phase phone-complete.

Known transport failures permit at most two fresh funded allocations per operation and 24 retained failures overall. The complete failed allocation remains charged, original claims are not replayed, and prior verified checkpoints remain intact. Hash, geometry, ownership, permission and metadata failures are not retried as transport failures. A verified-but-interrupted controller handoff re-audits the existing two job receipts instead of rebuilding content.

Local package unit tests and historical dispatcher/handoff regressions are exercised before candidate publication. The full metadata layout fixture covers all 34,750 jobs and 278,278 raster positions with synthetic metadata; its byte sizes are test inputs, not a forecast of actual download size. Live Cloud metadata inventory and package readback have not run yet. The candidate is not deployed, and the ChatGPT scheduled automation remains disabled.
